Shbace Medical · Usage Analytics

Private administration dashboard

Counts represent registered app installations/devices, not necessarily unique people. Analytics records a random installation ID and at most one activity timestamp per UTC day. For PWA, it records the hostname associated with each installation to separate counts by link. Older installations are attributed when they next send activity, and an existing source is never replaced. Only the hostname is stored, not the full URL, referrer, query string, IP address or User-Agent. It does not collect student names, phone numbers, precise location, study content, answers, scores, notes, bookmarks or saved progress.
